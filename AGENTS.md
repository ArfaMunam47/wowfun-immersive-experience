# WOW FUN — Project Guidelines

Guidelines for maintaining and developing the WOW FUN immersive beverage web application:

- **Framework**: TanStack Start with Vite and React 19.
- **Styling**: Tailwind CSS with Lexend typography and custom brand color tokens (`--mint`, `--sun`, `--coral`, `--pink`, `--ink`).
- **Motion**: GSAP and ScrollTrigger for fluid product showcases, flavor switching, and animations.
- **Brand Identity**: Preserves all interactive flavor transitions, custom cursor interactions, and responsive layouts.
