# 🥤 WOW FUN

### An Immersive Beverage Experience

**Bold Design. Playful Interactions. Creative Engineering.**

WOW FUN is a vibrant, interactive beverage website that brings digital storytelling and creative frontend development together.

From animated beverage cans and expressive typography to immersive product showcases and smooth scroll interactions, every section is designed to make browsing feel like an experience rather than just another website.

Built to explore the intersection of **design, motion, and modern frontend engineering**.

## ✨ Features

🎨 **Expressive Visual Design**  
Bold typography, playful illustrations, pastel palettes, and striking editorial layouts.

🥤 **Interactive Product Showcase**  
An animated beverage carousel featuring smooth product transitions, dynamic content, and engaging interactions.

🎬 **Immersive Animations**  
Fluid motion, scroll reveals, subtle floating effects, and carefully crafted transitions.

🖱️ **Creative Microinteractions**  
Interactive buttons, refined hover states, and responsive visual feedback.

📱 **Responsive Experience**  
Layouts designed to adapt across desktop, tablet, and mobile screens.

📖 **Editorial Content**  
Creative article layouts, interactive category filters, and engaging brand storytelling.

💬 **Interactive FAQ**  
A smooth accordion experience with accessible controls.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React | Component based frontend development |
| TypeScript | Type safe application logic |
| Tailwind CSS | Responsive styling |
| GSAP | Advanced animations and motion |
| ScrollTrigger | Scroll based interactions |
| Lucide React | Interface icons |

## 🎯 Project Vision

The goal behind WOW FUN was simple:

**What if a beverage website could feel like an interactive piece of digital art?**

Instead of following conventional layouts, this project explores how creative typography, product focused animation, visual storytelling, and thoughtful interactions can transform an ordinary browsing experience into something memorable.

It is also an exploration of my growing skills in creative frontend development and interactive web design.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ArfaMunam47/wowfun-immersive-experience.git
```

Navigate to the project:

```bash
cd wowfun-immersive-experience
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.
